# 나의 가계부

개인용 가계부 웹 앱입니다. 설치나 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 기능

- 수입/지출 내역 추가·수정·삭제 (날짜, 금액, 카테고리, 결제수단, 메모)
- 월별 보기 및 수입·지출·잔액 요약
- 월 예산 설정과 사용률 표시
- 카테고리별 지출 도넛 차트
- 내역 검색 및 수입/지출 필터
- 카테고리·결제수단 직접 관리
- JSON 백업/복원, 월별 CSV 내보내기 (엑셀에서 열림)
- 다크 모드 자동 지원, 모바일 화면 대응

## 데이터 저장

모든 데이터는 사용하는 브라우저의 `localStorage`에만 저장되며 외부로 전송되지 않습니다.
브라우저 데이터를 지우면 내역도 사라지므로 **설정 → 백업 (JSON)** 으로 주기적으로 백업하세요.
다른 기기/브라우저로 옮길 때도 백업 파일을 **복원**하면 됩니다.

## 파일 구성

- `index.html` – 화면 구조
- `style.css` – 스타일
- `app.js` – 동작 및 저장 로직
